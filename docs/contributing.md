# Contributions

Only a collaborator can push to this repository or open a pull request. The owner decides who is a collaborator, and the owner is currently the only collaborator. Every other person can use an issue for a reproducible bug report or a feature suggestion. The owner decides which changes to implement. Report security issues privately with [SECURITY.md](../SECURITY.md).

The owner pushes to `develop` directly. The `develop` ruleset requires a pull request from every other writer. For the branch, check, and release process, see [CI/CD](ci-cd.md).
