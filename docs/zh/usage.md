# 使用手册

## 选择桌面版还是 Web 版

| 模式 | 账号与数据 |
| --- | --- |
| 桌面版 | 首次启动创建本地身份。核心内容保存在本设备，无需云端账号。 |
| Web 版 | 用服务地址注册或登录。内容和附件保存在该服务端。 |

两种模式共用工作空间界面，当前不自动同步数据。桌面本地身份不等同于 Web 账号。离线模式不保证外部网站或网络链接在断网时可用。

## 安装桌面版

从仓库的 GitHub Releases 页面下载已发布版本。草稿和候选产物供维护者使用。

选择系统与 CPU 对应的包。解压平台 ZIP 后检查附带的 `SHA256SUMS`。不要混用不同架构的安装器。

| 平台 | 安装格式与步骤 |
| --- | --- |
| Linux x64 | 用发行版包管理器安装 DEB 或 RPM。给 AppImage 执行权限后运行。 |
| Windows x64 | 运行 EXE 或 MSI，按安装器提示完成。 |
| macOS Intel | 打开 `darwin-x64` DMG，把应用复制到 Applications。 |
| macOS Apple Silicon | 打开 `darwin-arm64` DMG，把应用复制到 Applications。 |

安装包携带 Node、PocketBase 与媒体处理运行时。使用者无需安装 pnpm、Rust 或其他开发依赖。Linux 仍需满足目标发行版的 WebView、系统库与媒体解码要求。dBrain 不宣称支持所有 Linux 发行版。

以下示例中的文件名应替换为实际下载文件。

```bash
# Linux AppImage
chmod +x dBrain.AppImage
./dBrain.AppImage

# Debian / Ubuntu
sudo apt install ./dBrain.deb

# Fedora 等 RPM 系统
sudo dnf install ./dBrain.rpm
```

当前内部候选没有正式签名与公证。Windows 可能显示未知发布者或 SmartScreen 提示。macOS 可能要求在“系统设置 → 隐私与安全性”中确认“仍要打开”。只对来源已验证的包操作。设备管理策略可能阻止继续安装。

参考说明：

- [Apple 说明](https://support.apple.com/en-lamr/102445)
- [Microsoft 说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)

## 第一次进入

桌面版启动时初始化本地数据、后端与身份，然后显示工作空间。等待初始化完成。出现连接错误时使用界面的重试入口。同一数据目录不要同时运行多个实例。

Web 用户打开维护者提供的服务地址，在注册页创建应用用户，然后登录。PocketBase 运维超级管理员不是应用登录账号。页面一直加载时先联系部署维护者。维护者检查服务与代理配置。

## 工作空间与内容

1. 在工作空间选择器中选择现有空间，或用新建入口创建空间。
2. 在图谱中选择视图。右键空白画布打开添加节点菜单。
3. 为内容选择节点类型。打开编辑器填写内容或上传附件。
4. 用节点菜单和关系菜单更改语义与连接。用视图配置与筛选控制显示范围。
5. 切换到 Dashboard，用工作空间组件和数据视图组织工作。

节点类型有文本、富文本、图片、PDF、视频、音频、网页、网站、集合和数据库。关系连接两个节点。标签与语义为节点分类。工作空间是内容的范围。视图是应用显示内容的方式。

工作空间选择器在图谱侧栏和 Dashboard 左侧栏中。自己拥有的工作空间显示「⋯」菜单，其中有「编辑」。非默认工作空间还有「删除」。只有所有者能看到这些入口。非所有者不能编辑或删除共享工作空间。

「编辑」更改名称和图标。对话框显示当前名称和图标。新建入口也提供同样的图标选择。应用会去掉名称首尾的空白。名称须为 1 到 50 个字符，且不能为空。图标可选 Emoji 或内置图标；未设置图标时显示地球图标。编辑只改工作空间本身。节点、关系和视图保持不变。

「删除」删除非默认工作空间。确认框显示名称。删除会一并移除该工作空间的节点、关系、视图、语义、标签和 Dashboard 页面，且无法撤销。资源库中的文件不会删除，仍留在资源库中。删除当前工作空间时，应用会打开另一个工作空间。

每个用户都有一个默认工作空间。应用在首次登录时创建它。默认工作空间不能删除。可以重命名和更换图标。每个工作空间都有一个默认视图。它显示全部内容。默认视图不能删除。可以重命名和固定。默认名称使用界面语言。英文界面中为「Default workspace」和「All」。重命名后显示自定义名称。

网页节点把页面作为资源库中的一个文件保存。节点只记录该文件的地址和字节数，与 PDF 节点保存 PDF 的方式相同。选择「文件上传」上传本地 HTML 文件，或选择「从资源库选择」引用资源库中已有的网页；「编辑器」从空白文档开始，「保存」会把它存成新的文件。「预览」在沙箱中渲染存储的页面，「编辑」读回源码并把修改保存回存储的文件。网页文件受存储策略中「网页」分类上限的限制（默认 16 MiB）。删除资源库中的该文件会清空节点地址，节点回到空界面。

### 从媒体网站导入

视频节点的空区域提供「本地上传」「从视频网站添加」和「从资源库选择」。音频节点提供「本地上传」「从音乐网站添加」和「从资源库选择」。选择网站卡片，粘贴页面地址。

导入由服务端运行 yt-dlp。Web 与容器格式已包含 yt-dlp。桌面安装包没有包含。桌面版请把 `yt-dlp` 放入 PATH，或用 `YT_DLP_PATH` 指定其路径。

| 类型 | 固定站点 |
| --- | --- |
| 视频 | B 站、抖音、小红书、YouTube、TikTok |
| 音频 | 网易云音乐、QQ 音乐、喜马拉雅 |

对话框为每个固定站点显示一个胶囊。地址属于某个站点时，该胶囊高亮。yt-dlp 支持但不在清单内的站点仍可导入，只是没有胶囊。

选择「解析」读取页面。对话框显示封面、标题、歌手或上传者、时长和可用清晰度或音质。选择一项后点「导入」。

- 视频清晰度有：最佳、2160p、1440p、1080p、720p、480p。对话框显示每项的预估大小。
- 音频音质有：无损、极高、较高、标准。对话框只显示站点实际提供的档位。
- 需要登录或会超过存储上限的档位会置灰并显示原因。

长视频或长音频的导入需要数分钟。点「导入」后对话框关闭，空区域显示阶段和百分比：先「下载」，再「保存」；视频随后「转码」，音频随后「准备」。关闭节点编辑器再打开，进度仍会保留，因为服务端继续工作。刷新页面也会从服务端恢复进度。

服务端重启或应用退出时，导入任务会中断。重新打开节点，选择「继续」从已下载的部分继续。服务端保留中断任务 24 小时。

选择「取消」停止导入。服务端停止下载并删除部分文件。导入失败也会删除部分文件，并重新打开对话框、保留地址和原因。再次选择「导入」会从头开始。

专辑或播放列表地址只导入第一首。本版本不批量导入。

导入的文件计入存储配额，并受分类上限约束：默认视频 2 GiB，音频 512 MiB。节点把原始页面地址记录为来源（`source: online`、`sourceUrl`）。

#### 站点登录

部分内容需要登录：高视频清晰度、高音频档位、会员内容或年龄限制内容。登录区位于导入对话框内：展开「站点登录」或点击站点胶囊即可连接站点。dBrain 不保存账号密码。

- 方式 A，仅本地后端：选择一个本机已安装的浏览器。服务端在下载时读取该浏览器的 Cookie，只保存浏览器名，因此 Cookie 不会过期。远程部署不显示此方式。
- 方式 B，Web 与桌面版：选择或拖入浏览器扩展导出的 `cookies.txt`。登录区提供 [Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc) 的链接，该扩展在浏览器内生成这个文件。一个文件可以包含多个站点的 Cookie，所以一次导出可以同时点亮多个胶囊。dBrain 只保留清单内站点的 Cookie，其余域在保存前全部丢弃。

胶囊显示登录状态。登录类错误会把胶囊置为失效。在登录区重新连接站点，然后再次「解析」。公开页面不登录也能导入。

#### 字幕、歌词与封面

每次导入时，dBrain 向站点请求一条字幕或歌词轨道，并自动选择：先界面语言，再原声语言，然后英语，然后第一条人工轨道，最后第一条自动轨道。该轨道进入媒体侧栏的「字幕」标签页。在那里点击一行可跳到对应时间。视频节点播放时，当前字幕行会以白字黑底显示在画面上方；控制条上的字幕按钮可以随时打开或关闭它，悬停按钮会显示「显示字幕」或「隐藏字幕」。没有导入字幕后按钮变灰，此时没有可显示的字幕。dBrain 不保存字幕文件，因此轨道不计入配额。没有字幕的页面照常导入，只是没有字幕。本版本不支持切换多种语言，也不生成字幕。

站点缩略图会成为节点和预览卡的封面。服务端把封面存为该资源的派生图片。资源库不单独列出它，但它计入配额。没有站点缩略图的视频使用视频画面的一帧。没有封面的音频不显示封面。

媒体侧栏可以收起。点击标签页旁的按钮即可隐藏侧栏，把宽度让给画面。播放器旁的窄条可以重新展开侧栏。「加笔记」或点击进度条上的笔记标记也会自动展开，因为两者都要在侧栏里显示内容。

#### 导入错误

| 提示或情况 | 处理方式 |
| --- | --- |
| 对话框要求登录，或导入报登录错误 | 用方式 A 或方式 B 连接站点，然后再次「解析」。 |
| 导入报会员错误 | 站点只向付费账号提供该内容。换一个档位或页面。 |
| 导入报大小或配额错误 | 选择更低档位，或在资源库删除资源。 |
| 导入报不支持的地址 | 检查地址，使用单个视频或单曲页面。专辑或播放列表只导入第一首。 |
| 导入报网络错误或超时 | 服务端已删除部分文件。再次选择「导入」。 |
| 导入报服务端繁忙 | 服务端每个用户最多同时 2 个导入，全局最多 4 个。等待一个导入结束。 |

富文本编辑器里，第一次按 Ctrl+A（macOS 为 Command+A）选中当前块，第二次选中全文。复制时纯文本以 Markdown 写入剪贴板。图片等没有文字形式的节点不会写入复制的文本。

在富文本编辑器中粘贴的文本按 Markdown 解析并转换为富文本。含全角标点的粗体与后面的文字保持分开：`**（Decimal）**和**（Hexadecimal）**` 得到两段粗体，中间的「和」保持普通。单个 `~` 按原样保留。删除线使用 `~~文字~~`。

删除内容前检查菜单的作用对象是节点、关系还是选中集合。重要资料先备份。

图谱和 Dashboard 使用同一工作空间的数据。数据库内容支持表格、看板、日历、图表等数据视图。可用配置以当前界面入口和内容类型为准。媒体上传后的解析、封面和转码需要时间。失败时保留报错和文件类型，供维护者排查。

Dashboard 把界面元素放进左右两个侧栏。左侧栏放页面和工作空间，右侧栏放组件库。指针移到屏幕边缘时，对应的侧栏浮出显示。用标题栏的两个按钮把侧栏固定。侧栏内的按钮把浮动的侧栏固定，或把固定的侧栏关闭。侧栏固定时，标题栏上对应的按钮隐藏。把当前节点加入组件库，在节点编辑器标题栏选择 Dashboard 按钮。

### 附件上传

单个附件最大 2 GiB。应用按大小自动选择上传方式。使用者无需设置。

- 32 MiB 以内的文件一次上传完成。
- 大于 32 MiB 的文件按 8 MiB 分片上传。客户端只发送缺失的分片。网络中断、刷新页面或重启后端后，再次选择同一文件。上传从已完成的分片继续。
- 服务端在本机磁盘拼装分片，然后把文件存入文件库。这一步可能持续较长时间。页面显示进度。这一步关闭页面不会丢失文件。重新打开页面后可以看到结果。
- 取消上传后分片留在服务端。再次上传同一文件即可继续。

服务端在开始上传前拒绝大于 2 GiB 的文件。编辑器内图片另有更小的上限（5 MiB）。这个上限与节点附件上限不同。

PDF 超过 256 MiB 时跳过解析。应用只保存文件。仍可下载和打开，但没有页数和封面。视频按磁盘流式转码。大小不影响 HLS 生成。

PDF 预览器先显示已保存的第一页封面，再用渲染出的页面替换它。预览器只读取当前页面用到的部分。它不会先下载整个文件；定位页面时直接读取页树中该页的条目，而不是把每一页的条目都读一遍，因此页面分散存储的大体积扫描件也能较快打开。预览器在你滚动到后续页面时再读取。

应用按读者和节点分别记住上次页码。重新打开节点即从该页继续。大纲按层级折叠，选择父项可展开或收起，长标题自动换行。

## 资源库与引用

在灵动岛选择 资源库 打开媒体资源库。页面列出你上传的文件，并按图片、视频、音频、PDF、网页、其他分类。服务端由这些文件派生的封面与 HLS 分片不会单独列出，但会计入存储面板，并随资源一起删除。可以按名称搜索，也可按分类筛选。存储面板用一条分段条显示已用字节与总配额，每类一种颜色，下方图例列出各类字节数。配额与单文件上限由维护者设置（见运维手册与开发手册）。内置默认值给每个用户总计 10 GiB，单张图片 32 MiB，单个网页 16 MiB，单个音频 512 MiB，单个 PDF 512 MiB，单个视频 2 GiB，其他单个文件 256 MiB。

资源库也可以上传文件、重命名标签、复制地址和删除资源。重命名只改标签，不改存储的字节和地址。删除资源会删除存储的字节、它派生的封面或 HLS 包，并释放对应的全部配额。确认框会列出引用该文件的节点。删除后这些节点保留内容，但资源链接变为空，媒体区域显示空状态。

删除节点默认**不会**删除它的文件。节点引用了已上传资源时，节点菜单和编辑器标题栏的删除入口会询问：只删除节点，还是连同它引用的已上传文件一起删除。选择只删除节点会保留资源库中的文件；孤立文件会一直留在那里，直到你删除它。编辑器标题栏菜单还有「清空节点」，清空节点内容时也会询问如何处理它引用过的文件；集合节点和数据库节点没有清空操作。配额看起来将满时查看存储面板。

要引用已经存储的文件，打开需要媒体文件的节点，点击它的添加区域，选择「从资源库选择」。在对话框中选择一个文件；节点保存的是对该文件的引用，而不是副本。共享工作空间中的节点可以引用协作者上传的资源，选择器会把这类文件标为 共享。解析结果保存在资源上，所以只做一次：第一次解析 PDF 或打包视频时，页数、封面、播放列表和时长会写入该资源，之后引用它的节点直接复用这些结果，不再重新解析、转码或存储任何内容。图片与音频的尺寸和时长同样只测量一次并保存在资源上；只有资源上还没有测量值时才从文件读取。

引用不是副本。之后删除该资源时，所有引用它的节点都会失去链接并显示空状态；节点本身与其它内容保留。节点仍在使用的资源请保留。

Excalidraw 块的预览图与原始场景保存在同一个文件中。每次保存都原地更新这个文件，因此反复编辑不会新增资源；节点不再保存内联副本时，打开块仍会从该文件恢复场景。

桌面版中资源库管理本地工作空间的文件。总配额使用内置默认值；桌面版没有可修改它的部署运维者。

## 数据保存与备份

桌面版的数据库、附件、本地身份和日志保存在系统应用数据目录。通常可用标识 `cn.dbrain.desktop` 定位。实际目录以平台接口和运行日志为准。Linux 常见路径为 `$XDG_DATA_HOME/cn.dbrain.desktop`。未设置该变量时，路径为 `~/.local/share/cn.dbrain.desktop`。

备份前完全退出应用。检查后台进程已停止。把**整个应用数据目录**复制到安全位置。不要只复制数据库文件。附件和本地身份也要保留。

恢复前先保留当前目录副本。然后关闭应用，恢复匹配版本的完整数据。

Web 用户的数据由维护者备份。浏览器缓存不等同于服务端备份。dBrain 不承诺通用的跨端一键迁移。迁移需求须由维护者检查。

## 升级与卸载

已安装的桌面应用每次启动时通过 HTTPS 检查最新已发布 Release。若对应平台存在更新版本且更新包已签名，应用会下载、验证更新签名、安装并重启。检查失败时仍可离线使用。首个接入更新器的版本需要手动安装。

Tauri 当前传输完整更新包。这是版本增量升级，不是按字节差异传输的补丁。升级不替换应用数据目录。桌面运行时在版本迁移前会备份数据，并在 `backups` 目录只保留最近两次迁移快照，更早的会删除。但不能替代你的外部备份。

卸载程序与删除个人数据是两个不同的操作。不要假定卸载器会删除数据。需要删除数据时，退出应用，查看应用数据目录，先备份，再手动删除。回滚时使用旧版本的数据备份。旧版本不一定能直接打开已迁移的数据库。
