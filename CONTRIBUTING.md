# Contributing to dBrainX

dBrainX is free software under AGPL-3.0-only. The owner develops and releases it independently. Only a collaborator can push to this repository or open a pull request, and the owner is currently the only collaborator. Everyone else can report a reproducible bug or suggest a feature in an issue. The owner decides whether and when to act on it. For a security issue, use the private reporting process in [SECURITY.md](SECURITY.md) and do not put exploit details in a public issue.

The owner pushes to `develop` directly. The `develop` ruleset requires a pull request from every other writer. [CI/CD](docs/ci-cd.md) documents the owner's development and release process. Chinese instructions: [贡献说明](docs/zh/contributing.md).
