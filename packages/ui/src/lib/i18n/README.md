# 界面语言

网页端和桌面端共用中英文翻译资源。默认语言为简体中文；用户可在侧边栏底部选择“中 / EN”。选择保存在 `localStorage` 的 `dbrainx.locale` 中，刷新和下次启动后仍然有效，同一来源的其他标签页也会同步。存储不可用时仍可切换，当前页面会保留选择。

两个应用的根布局挂载 `LocaleInitializer`，读取已保存的语言并更新 `<html lang>`。组件使用 `useI18n()` 订阅语言变化，通过返回的 `t` 翻译界面文案。切换语言不会重建整个工作空间或编辑器。

新增文案时，在 `messages.ts` 中同时填写 `zh-CN` 和 `en`。源文案作为翻译键；缺少翻译时显示源文案。带变量的句子使用 `{name}` 占位符，并传入变量对象，不要拼接多个翻译片段。

只翻译应用提供的界面文案。用户填写的节点标题、正文、标签、语义类型名称和数据库字段名称不得传入翻译函数。纯辅助函数可使用 `runtime.ts` 的 `translate`；模块级配置的标签使用 getter，在读取时获取当前语言。缓存中含有翻译结果时使用 `useLocaleMemo`，让语言变化触发重新计算。

验证语言默认值、存储恢复、切换通知、多标签页同步、完整句子的变量替换与资源一致性：

```bash
node --test packages/ui/src/lib/i18n/runtime.test.ts
```
